# ClawBot实例管理器 v1.4.0

## 变化

- 主窗口采用确认的浅色淡紫设计，按首页、实例与服务、模型与人设、权限与能力、软件更新五页导航。
- 账号共享的五小时/每周额度直接展示在首页，剩余数字、已用进度条与重置时间分层呈现；仅多个分组时显示分组选择。
- 首页显示实例总数、服务运行与待处理队列；精简实例表提供查看聊天及更多菜单，菜单按实例标识定位，刷新保留未变化的行。
- 统一浅色侧栏、淡紫选中态、圆角卡片和清爽表格；更新、连接、人设和聊天窗口共用按钮样式。服务、模型和权限页显示实例选择，首页和软件更新隐藏无关选择条。
- 模型列表暂时不可用时，仍显示实例当前模型与推理强度，避免空白配置。
- 保留现有权限、模型、人设、聊天、服务控制、首次连接和更新安装行为。
- 放大聊天及更多按钮热区，增强额度数字/正文/菜单对比，使用淡紫与淡蓝额度卡片和圆角菜单；按钮内容不截获鼠标命中。更新源文件后须重开管理器加载。

## 验证

- WPF 自检覆盖五页切换、按页选择器、刷新后选择保留、真实行按钮目标，以及管理器、人设、聊天、首次连接、更新窗口加载。
- WPF回归核对未知/零/完整额度、多分组选择、空实例和 1020×700、1320×900、1700×1000 三档布局；实际管理器显示原实例与首页额度。
- Node 软件测试与包审计在源码提交前执行，具体结果见 `docs/VERIFICATION.md`。
