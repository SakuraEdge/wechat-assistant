# ClawBot实例管理器 v1.4.0

## 变化

- 主窗口改为左侧导航，按概览、实例与服务、权限与能力、模型与人设、账户额度、软件更新分页。
- 顶部统一切换当前实例；额度与更新页面明确标注为账号级或软件级数据。
- 概览新增实例总数、服务运行和待扫码摘要，实例表保留关键状态与最近接收时间。
- 统一深色导航、青绿色操作强调、圆角输入框和表格样式；更新、连接、人设和聊天窗口同步采用新配色。
- 模型列表暂时不可用时，仍显示实例当前模型与推理强度，避免空白配置。
- 保留现有权限、模型、人设、聊天、服务控制、首次连接和更新安装行为。

## 验证

- WPF 自检覆盖六个分页切换、全局实例选择器及管理器、人设、聊天、首次连接、更新窗口加载。
- 实际打开管理器读取两个既有实例并进行六页截图核对；Windows 200% 缩放下无文字遮挡或控件重叠。
- Node 软件测试与包审计在源码提交前执行，具体结果见 `docs/VERIFICATION.md`。

## 发布状态

本版本已进入源码更新，正式安装包与 Release 状态以 README 和 GitHub 发行页为准；仅在完成安装生命周期与资产校验并实际发布后才能称为已发布。
