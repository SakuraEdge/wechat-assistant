# 安装包安全告警排查

2026-10-23 收到 Windows Defender 对 v1.4.0 安装器的 `Trojan:Win32/Sabsik.TE.A!ml` 告警报告。此报告仍待受影响电脑及微软复核，不能依据本机未检出就称为误报。遇到告警时暂停运行对应安装包，不添加排除项或允许项。

## 已核对的公开文件

| 文件 | SHA-256 |
| --- | --- |
| v1.4.0 Windows x64 安装器（31,061,380 字节） | `6ad62f1964eb79532d6bc1527da7115ee5ba36dedea587c77acd539577752c81` |
| v1.4.0 便携 ZIP | `65e0662e5510820802c1d9bb6eba4609d3e59feb3d97b1e1bb4526e150d475e4` |

- 公开发行资产的大小、SHA-256 与本地发行文件一致；97 个分发源码文件与对应提交 a06951a 的字节一致。安装清单记录 405 个有效载荷文件。哈希一致表示来源和字节一致，不等于文件没有恶意行为。
- 构建用 Inno Setup 6.7.3 安装器与固定下载哈希一致，Authenticode 有效；内置 Node 24.16.0 的哈希与固定官方版本一致，签名为 OpenJS Foundation。ClawBot 启动器及安装器自身目前未签名，不能把依赖签名称为本软件签名，也不能据此解释具体木马告警。
- 本地 Defender 引擎 1.1.26090.9、情报版本 1.461.156.0 对上述安装器和便携 ZIP 的诊断扫描均返回 0、未报告威胁。实时防护保持启用；没有添加排除项、恢复隔离文件或修改允许列表。此结果只适用于该时间、该本机扫描，不覆盖另一台电脑的云端检测或运行行为。
- 未取得受影响电脑上文件的 SHA-256、检测日志和微软最终判定，因此不声称已确认误报、已清除感染或新版本不会触发告警。

## 受影响电脑的核对步骤

1. 暂停运行告警文件，保留 Windows 安全中心的完整告警名称、受影响文件、时间和情报版本。若已经允许该威胁，请由本人在 Windows 安全中心撤销该允许，并按 Defender 建议处理与扫描。
2. 在 PowerShell 中对实际下载文件运行 `Get-FileHash -Algorithm SHA256 -LiteralPath '完整安装包路径'`，核对上述已公开哈希。不要为了取得文件而从隔离区恢复或绕过拦截；哈希不一致时不要运行。
3. 从[微软文件分析入口](https://www.microsoft.com/en-us/wdsi/filesubmission)以软件开发者身份提交公开安装包、哈希、检测名称和复现信息，等待最终判定。提交文件前确认不含私人数据；不上传账号配置、聊天、凭据或整个工作区。维护者尚未取得本次的微软分析单号。
4. 安装器和本地源码是不同交付物。初始化客户端连接不会修复旧安装器；修复代码需使用包含它的新包。代码签名和杀毒扫描均不能保证所有电脑不再告警。

## 后续构建检查

`tools/build-release.mjs` 构建 EXE 和 ZIP 后调用 `tools/scan-release.ps1`，使用本机启用的 Defender 逐包诊断扫描，记录情报/引擎版本、文件大小及哈希。检测到威胁、扫描异常或 Defender 不可用时中止，不自动修改防护设置。发布工具在创建/更新草稿前再次扫描。扫描记录留在构建临时目录，由维护者保留；它不是微软复核结论。

诊断扫描的 `-DisableRemediation` 只禁止此次自定义扫描自动处置；它会扫描归档并报告检测，不会关闭实时防护。依据[微软命令行说明](https://learn.microsoft.com/en-us/defender-endpoint/command-line-arguments-microsoft-defender-antivirus)。争议检测的提交流程见[软件开发者 FAQ](https://learn.microsoft.com/en-us/defender-xdr/developer-faq)。
