# 换电脑与交接

仅复制本软件文件夹或GitHub源码，不带旧机器Windows配置目录、DPAPI、队列、二维码、账号或提供商密钥。聊天历史和其他项目文件不在包内，需正常迁移。

新电脑安装Node24+及Codex，登录自己的现有模型提供商/账号，保持客户端运行。让该电脑的ChatGPT/Codex读本文件、README、FEATURES和OPERATIONS后执行initialize.ps1；随后双击，创建primary扫码，再创建其他用户。不声称在未经测试的另一电脑已验证成功。

可交给其他ChatGPT的指令：

> 请维护这个微信助手软件包。先阅读README.md、docs/FEATURES.md和docs/OPERATIONS.md。保留GPT-6.1 Sol/high与我的当前提供商和平台审批。primary是完整业务授权主用户，其他默认日常用户，角色以绑定策略为准。认证只留Windows用户目录DPAPI，不复制或输出。安装Node24依赖，在当前Codex环境执行initialize.ps1，然后打开WPF界面逐一扫码；验证文字、图片、文件和所需跨项目能力，记录实际证据。不要自动上传GitHub或替换已有账号。

同机移动软件目录通常保留注册信息，但运行脚本可能仍指向旧位置。先空闲停止服务，用新位置重启并核对状态。工作区路径不会自动迁移；需用受支持Relocate操作重新验证。应用更新/重启导致连接缓存失效时从当前客户端刷新。首次失败应检查依赖和正常登录，不拷贝他人认证或改系统安全设置绕过问题。
