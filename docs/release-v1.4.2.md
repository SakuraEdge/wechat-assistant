# v1.4.2 · 聊天公式显示

Windows 10/11 x64。提供EXE安装器、内置Node的便携ZIP、安装清单和SHA-256文件；其他平台尚未适配。

- “查看聊天”默认在本机排版LaTeX公式：`$...$`、`$$...$$`、`\(...\)`、`\[...\]`。支持常见分式、根号、上下标、求和积分、矩阵、aligned及cases，兼容直接输入的乘除号与中文单位。
- 新增“查看原文”和“复制原文”；复制内容保留原始公式。代码中的公式标记和普通美元金额保留为文字；不支持或未闭合的公式保留原文。
- 内容未变时复用文档，刷新时保留阅读位置。渲染组件缺失或校验失败时显示原文。
- 固定WPF-Math/XamlMath.Shared 2.1.0与字体许可随两种软件包离线分发，无需浏览器、外部公式服务或完整TeX安装；不宣称兼容全部LaTeX文档语法。

61项软件测试、WPF检查和真实聊天鼠标操作已通过。发行流程验证独立源码、隔离安装、从1.4.1升级、卸载及分发文件哈希，详细范围见[验证记录](VERIFICATION.md)。完整鼠标点击“安装更新”链路及生产服务自动恢复仍沿用既有未完成验收的标注，不能用安装组件检查替代。

账号、提供商、模型、权限、人设及聊天继续保存在原Windows用户目录，不随包分发。v1.4.0的Defender告警仍待微软及受影响电脑复核；本版的本地扫描不代表告警已解决，安装器尚无发布者代码签名，见[安全排查记录](SECURITY.md)。
