# v1.4.1

Windows 10/11 x64。提供EXE安装器、内置Node的便携ZIP、安装清单和SHA-256校验文件；其他平台尚未适配。

- 更新下载显示真实进度条、已下载/总大小、平均速度和预计剩余秒数。校验阶段单独提示，只有大小与 SHA-256 核对通过才到 100% 并允许安装；关闭再打开更新窗口可继续观察当前下载。
- v1.4.1起，下载校验通过后点击“安装更新”并确认位置，即自动安装并打开新版。安装版升级自身目录；源码/便携版转入独立管理目录，保留原目录。未知非空目标、路径重叠与更高版本拒绝覆盖，不要求到下载文件夹手动启动。
- 安装占用检查按可执行文件或入口脚本归属判断，避免把无关 Node 程序的数据路径误判为软件占用。交接核对管理器进程启动时间，退出后等待安装目录进程释放；仍有占用时显示进程名/PID，不强杀任务。
- 修复直接 `detached` 启动隐藏PowerShell会提前退出的问题；改由独立隐藏进程接管，控制进程退出后仍可运行，准备失败时取消交接并由控制进程恢复已停止服务。
- 修复新增微信用户窗口的 XML 参数类型；首次引导“下一步”与首页新增入口均使用正确的窗口加载函数。增加 XML 对象和下载进度的 WPF 回归。
- 启动器将脚本名、行号和异常类型写入本机脱敏诊断，运行错误提示对应代码位置；不把所有窗口错误归因于 Node 或 PowerShell 缺失。
- 构建与发布增加本地 Defender 检查。v1.4.0 告警在本机未复现，仍待微软/受影响电脑复核；详见[安全排查记录](SECURITY.md)。本版本不声称已经解决 Defender 告警；安装包尚无发布者代码签名。

账号、绑定、提供商、模型与工作文件继续保存在原 Windows 用户目录，不随安装包分发。旧版包不会因本次发布而改写。59项自动测试、WPF及隔离安装组件检查通过；完整鼠标点击安装链路因电脑操作中止尚未完成，生产服务自动恢复未执行。详细结果与限制见[验证记录](VERIFICATION.md)。
