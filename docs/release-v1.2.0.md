## ClawBot实例管理器 v1.2.0 · Windows 一键安装版

推荐下载 **ClawBot-Instance-Manager-Setup-1.2.0-windows-x64.exe**，双击安装。无需管理员权限，无需安装Node/npm或自行编译；安装后自动打开管理器。

首次使用：**安装 → 在管理器复制连接提示到已登录的Codex完成初始化 → 本人微信扫码**。程序和依赖自动部署；本人登录、客户端连接与扫码需要用户完成。软件不附带账号或模型额度。

- 内置固定版本Node.js 24.16.0与扫码依赖，安装后检查文件完整性。
- 自动创建桌面、开始菜单入口和卸载项，不修改系统PATH。
- 首次连接向导检测配置并提供可复制提示，未完成连接时明确提示。
- 更新/卸载前检查该安装目录进程，不自动中断任务；卸载保留账号、实例、人设、模型、聊天与工作文件。
- 包含已有的多实例、权限、人设参考图、动态模型/强度、管理器聊天、文件图片及跨项目功能。

另有内置Node的便携ZIP。`SHA256SUMS.txt`提供EXE和ZIP校验值，`install-manifest.json`提供安装内容清单。安装包尚未添加发布者代码签名。

支持 **Windows 10/11 x64**，macOS/Linux与原生ARM64安装包暂未提供。电脑需要保持开机联网，Codex和微信接口可用。

验证范围：本机隔离目录安装/启动/卸载与现有用户配置保留；独立源码测试、包清单、哈希与WPF加载。未经另一台电脑实测的部分不作成功承诺。

使用教程：[README](https://github.com/SakuraEdge/wechat-assistant#readme)。
